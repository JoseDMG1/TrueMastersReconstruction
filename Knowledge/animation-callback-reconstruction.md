# Fighter animation callback reconstruction

Static evidence: `Evidence/fighter-animation-audit.json` contains prefab,
controller and direct-clip SHA-256 identities, controller behaviours and event
times for Sora and Amon. Generated by `Tools/audit-fighter-animation.cjs`.
This is a bounded YAML audit; blend-tree clip traversal is not included.

Sora's prefab uses `AirAnimatorController.controller` and Amon's uses
`char1_Animation_controller.controller`. Their regular attack clips call the
existing `SummonAttack.CreateAttack`, `AnimatorStatesManager.ChangeAtk/NoDelay`,
`AnimationMovement.goVertical/goHorizontal`, and `ColliderController` methods.
For example Sora BasicAttack creates its offline attack at .9166667 seconds;
Amon BasicAttack at 1 second. Earlier CreateNetworkAttack callbacks belong to
the online path. These event times do not prove that the current runtime
receives the events or creates projectiles; the main agent owns that validation.

`AnimatorEventsController` is not attached to either normal fighter prefab.
Its native CreateAttack (`0x1214018`) dispatches to AttacksController_LM;
StartAwakening/StartSpecial dispatch to Special_LM. It remains untouched rather
than wiring this local-multiplayer component into normal offline fighters.
`Evidence/native-disassembly-AnimatorEventsController.txt` preserves its native
bodies for later local-multiplayer work.

Implemented directly from correctly mapped ARM64 (source binary SHA-256
`d5669fa920c5034ec1ed5b7988149825430f65ea557ba7882567c0790da2dd8c`):

| Component | Native entry | Behavior |
|---|---|---|
| Recover | `0x12A7384` | Optional clearing of Stunned/Weak/Blocking, ResetTrigger Block, parent collider restoration; native constructor defaults keepStunned true |
| Stunned | `0x12B447C` | Sets Stunned true |
| StopGo | `0x12C5CD0` | Stops AnimationMovement when **next** state is hit1/hit2/Fall 3 |
| SlowSpeed | `0x12BEEFC` | Exit calls goHorizontal(.1); entry is native RET |
| RecoverReduceCollider | `0x1279294` | Reduces collider, or recovers it and clears Weak |
| ChargeSpecial | `0x122042C` | Compares next state to previous clip name, updates names from next clip, charges SpecialAtk by .03; respects Photon ownership online |
| MovementStateEvents | `0x1244A68` / `0x1244B98` | Layer UnityEvents; clears PlayerController_LM stuned/isBlocking/weak and calls ShieldManager.FinishShield |
| StopBlocking | `0x12B34D4` / `0x12B3B98` | Offline element shield dispatch and Blocking state; exit retains shield if current state is BlockHit |
| AirShieldController | `0x127D830`..`0x127DC54` | Animator binding; per-FixedUpdate scale/audio changes; shieldOn/Off flags |
| ShieldMannager | `0x12AEF50`..`0x12AF028` | Fire shield particles, audio volume/pitch and active flag |

Each class has a corresponding `Evidence/native-disassembly-TYPE.txt` generated
with the ELF VA mapping; Cpp2IL's invalid printed Disassembly was not used.
Generic usage slots were resolved to actual component owners, including
GetComponentInParent<ColliderController> (`0x28169A8`),
GetComponent<AnimationMovement> (`0x2817330`),
GetComponent<AirShieldController> (`0x2815470`) and
GetComponent<ShieldMannager> (`0x2815490`).

Native AirShield uses Vector3.Lerp once per physics tick (no deltaTime), grows
toward Vector3.one, shrinks toward .6 on each axis, decreases audio .01 per tick
and deactivates below .7 unless current/next state is BlockHit. The increase flag
clears only above 1 even though clamped Lerp normally approaches 1; that odd
native condition is retained rather than replaced by an assumed intention.

Reconstruction deviations: ChargeSpecial handles a missing next clip by returning
instead of indexing an empty array. MovementStateEvents emits its UnityEvent then
returns when PlayerController_LM is absent, preventing accidental use of its
LM-specific fields on normal fighters. StopBlocking's Photon RPC sends remain
unimplemented; the offline shield calls are restored. Its other-element shield
owners may still contain stubs: this pass restores Sora/Amon's Air and Fire
owners only. Death/respawn remain assigned to the scoring reconstruction.

No Unity process/backend was launched by this pass. No new runtime or compile
success is claimed here; the parent agent performs centralized validation.
Local RAG retrieval was attempted after documentation changed and correctly
refused its stale index; rebuild once all agents finish writing Knowledge.

Usage resolution confirms On (`0x2817168`), Blocking (`0x28154D0`),
CheckShields (`0x28179C8`), WaterShieldLeft(Clone)/WaterShieldRight(Clone)
(`0x28179D0`/`0x28179D8`), PrisonFree (`0x2814790`), ShadowBlockHit
(`0x2817A08`) and Hit (`0x2815AB8`). Generic usage resolution confirms
GetComponent<Animator> (`0x2814398`, `0x28143D0`) and
GetComponent<ChangeSize> (`0x28156D8`). Shadow floor transitions call the existing
LerpManager.LerpScale owner at `0x124139C` with easing enum 2 (EasyInOut).

Preserved native details: Water's scan sets a found flag shared by both sides;
it resets both booleans only when neither matching owned attack was found.
It does not independently clear one stale side while another shield remains.
ChangeSize launches concurrent coroutines rather than canceling prior transitions.
Empty native Update/Start methods remain empty where applicable.
